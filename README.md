# React Chatbot

A simple and responsive chatbot interface built with **React** and **Vite**.

This project was created to practice React fundamentals such as components, props, state management, event handling, effects, and component communication.

## Features

- 💬 Send and display user messages
- 🤖 Generate chatbot responses
- ⌨️ Send messages using the Enter key
- 🔄 Automatically scroll to the latest message
- 👤 User and robot message avatars
- 🎨 Responsive and clean chat interface
- 🧩 Component-based React architecture

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SidiAbdullah/react-chatbot.git
```

### 2. Navigate to the project

```bash
cd react-chatbot
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

## Chatbot Responses

The chatbot response functionality uses the `supersimpledev` package. The purpose of this project is primarily to practice building the **React interface and application structure**, rather than developing an AI chatbot backend.
